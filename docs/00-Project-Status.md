Project Aether is currently being developed design-first. Implementation has intentionally not begun so the v0.1 experience, architecture, responsibilities, data model, event model, settings, and UI direction can be validated before code is scaffolded.

The v0.1 architecture is now frozen for scaffolding. Future ideas that are not required to implement the frozen v0.1 scope should move to later roadmap planning rather than expanding the first scaffold.
